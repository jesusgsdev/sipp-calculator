# Contributing

Thanks for helping improve the UK Pension & SIPP Forecaster.

1. Fork and create a branch.
2. Make your change. The project is vanilla JS with zero dependencies — please keep it that way.
3. Run `npm test` (Node 20+). Add tests for any calculation change.
4. Open a pull request describing the change and, for tax/pension rule changes, link the official source (HMRC, gov.uk, PLSA).

This tool is for illustration only and is not financial advice.
