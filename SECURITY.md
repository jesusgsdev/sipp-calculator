# Security Policy

## Scope

This is a client-side web app: all calculations run in your browser and no personal data is sent anywhere. Relevant reports include XSS, unsafe handling of saved local profiles, or vulnerable CI/workflow configuration.

Incorrect pension or tax calculations are not security issues — please open a regular [bug report](https://github.com/jesusgsdev/sipp-calculator/issues/new?template=bug_report.md).

## Reporting a vulnerability

Please use GitHub's private reporting: **Security → Report a vulnerability** on this repository. Don't open a public issue for security problems.

You can expect an initial response within 7 days.

## Supported versions

Only the latest version deployed from `main` is supported.

This tool is for illustration only and is not financial advice.
